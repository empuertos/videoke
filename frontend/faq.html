🚀 Getting Started
What is VIDEoke YT?
VIDEoke YT turns any TV or laptop into a karaoke machine powered entirely by YouTube. Guests join with a 6-character party code or QR scan, browse the karaoke catalog, and reserve songs from their phones. The host screen plays them back-to-back, auto-skips broken videos, and announces each singer with an AI voice.
How do I start a party?
1. Tap 🎉 Start New Karaoke on the home page
2. Note your Party Code and Admin Password
3. Tap 📺 Open Host Screen — this shows the QR code for guests
4. Tap the screen once to enable auto-play
5. Share the QR code or party code with friends
6. Friends scan the QR or go to /remote?party=XXXXXX on their phone
How do guests join?
Scan the QR code shown on the host screen with your phone camera. Or open the site and tap 📱 Join a Party, then type the 6-character party code.
How do I reserve a song?
On the remote page, there are two ways:

🔗 Paste Link: Copy a YouTube link from anywhere (or use the ▶ Open YouTube App button), paste it, then tap ➕ Reserve

🔍 Search Song: Type a song name, tap ➕ Reserve on any karaoke result. Or use 🎤 voice search. Or tap a category chip.
What is the Admin Password for?
The admin password unlocks host controls: pause, skip, stop, volume, remove songs, reorder queue. Without the password, guests can only add songs — they can't change playback. This prevents guests from accidentally stopping the music.

Keep it private — only share with co-hosts you trust. The password is case-sensitive and 8 characters long.
💝 Free & Privacy
Is VIDEoke YT really free?
Yes — 100% free, forever. No fees, no ads, no signup, no paywall. You can optionally tip the developer via the QR code on the home page, but it's completely optional and the app will always work without it.
Are there ads?
No. Zero ad networks, zero sponsored content, zero popups, zero trackers.

⚠️ One honest caveat: the YouTube player itself may show ads if a specific video's uploader enabled ads on their video. This is YouTube's behavior, not the site. Pick videos from karaoke channels like Sing King, Stingray Karaoke, or most Filipino karaoke channels — those are ad-free.
Do you collect my data?
No. There's no analytics, no tracking pixels, no cookies. Only localStorage is used to remember your singer name and admin token on your own device. Nothing is sent anywhere except your own party's backend.
Do I need to create an account?
No. There's no signup, no login, no email required. Every party is anonymous and self-contained.
🔧 Troubleshooting
A video won't play / "This video is unavailable"
YouTube blocks some videos from being embedded on other sites. The system auto-skips these and moves to the next song in the queue.

To fix: Pick a different video — search for "<song name> karaoke" on the Search tab. Karaoke channels usually allow embedding.
Autoplay is blocked
Browsers require one user interaction before playing sound. When you open the host screen, a yellow overlay says "Tap Anywhere to Start" — tap it once, and from then on every song auto-plays.
Nothing plays after the first tap
Check:
  • Host screen shows "Connected" (green dot)
  • Party code on host matches what guests are using
  • Open DevTools console (F12) — YouTube IFrame API should have loaded
  • Refresh the host page if the YouTube player failed to initialize
Search returns nothing / "No karaoke version found"
Search uses free public Piped instances. If they're down, try:
  • Try a simpler search term (tadhana instead of Tadhana by Moira)
  • Wait a minute and retry — results are cached for 5 minutes
  • The site admin can set YOUTUBE_API_KEY for a fallback source
Admin password doesn't work
Passwords are case-sensitive. Copy-paste directly from the home page or from the host screen — don't retype.
The party disappeared after a while
Parties auto-expire after 24 hours of inactivity — this is by design. On Render's free tier, sessions also reset when the backend sleeps/restarts. Upgrade to a paid plan with persistent disk to keep parties across restarts.
🎬 How It Works
Can multiple TVs show the same party?
Yes. Open /host?session=<hostCode> on multiple devices with the same host code. They'll all receive playback commands and mirror the state — perfect for large venues with multiple screens.
Can guests see each other's songs?
Yes — the entire queue is visible to all guests in the party. This is intentional (karaoke is social!). Everyone can see who's singing what and how many are waiting.
How many people can join one party?
There's no hard limit on guest count — the backend supports hundreds per party. But the queue is capped at 50 songs, and each singer can have up to 5 songs in the queue simultaneously.
How many parties can run at once?
Each backend instance supports up to 300 simultaneous parties, each fully isolated with its own queue, history, and admin controls.
Does it work offline?
No — playback requires internet because videos stream from YouTube. The site can be installed as a PWA (Add to Home Screen) but won't play anything without a connection.
What is the "DUET" badge?
The search detects duet karaoke tracks (karaoke videos with both male and female parts on the audio). When you tap Reserve on a duet, it asks whether you'll sing the 👦 Boy Part or 👧 Girl Part. The AI announcer will then say "singing the boy part of..." so guests know what to expect.
