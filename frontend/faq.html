🚀 Getting Started (Host)
What is VIDEoke YT?
VIDEoke YT turns any TV or laptop into a karaoke machine powered entirely by YouTube. Guests join with a 6-character party code or QR scan, browse the karaoke catalog, and reserve songs from their phones. The host screen plays them back-to-back, auto-skips broken videos, and announces each singer with an AI voice.
How do I start a party?
1. Tap 🎉 Start New Karaoke on the home page
2. Note your Party Code and Admin Password
3. Tap 📺 Open Host Screen — this shows the QR code for guests
4. Tap the screen once to enable auto-play
5. Share the QR code or party code with friends
What is the Admin Password for?
The admin password unlocks host controls: pause, skip, stop, volume, remove songs, reorder queue. Without the password, guests can only add songs. Keep it private — only share it with co-hosts you trust.
📱 How to Use the Remote
How do I set my name as a singer?
At the top of the Remote page, type your name in the "🎤 Your Name (Singer)" box before reserving a song. This way, the TV screen will announce your name properly (e.g., "Next up, Juan!").

If you leave it blank, the system will automatically assign you a Guest name (like "Guest 123") so you can still sing and track your turn!
How do I reserve a song?
On your phone, you have two easy ways to add a song to the queue:

1. Paste Link: Go to YouTube, search for the karaoke video you want, tap Share → Copy Link. Go back to VIDEoke, paste the link, and tap ➕ Reserve.

2. Search Song: Type the song name directly in the app. We filter out non-karaoke videos so you only get the best backing tracks. Tap ➕ Reserve.
What is the "Open YouTube App" button?
This is a shortcut! Tapping it will open the native YouTube app on your phone so you can search for a karaoke video faster. Once you find one, just copy the link and paste it back into VIDEoke.
What does the 👥 DUET badge mean?
Some karaoke tracks have both male and female parts. If you pick a duet, the app will ask if you want to sing the 👦 Boy Part or 👧 Girl Part. The TV screen will automatically announce which part you are singing so the crowd knows!
How do I switch or change the party code?
If you typed the wrong code or want to join a different party, you can easily switch!

Just tap the Party Code at the top header (it has a ✏️ icon) OR scroll down to the Share section and tap the red 🚪 Change Party Code button. A confirmation will appear, and you can enter the new code.
Do I need an Admin Password to request a song?
No, you don't! Anyone who joins the party can search or paste a YouTube link and tap ➕ Reserve without entering any password. The Admin Password is only needed for controlling the playback (Pause, Play, Skip) and managing the queue (moving/deleting songs). So go ahead and request your songs freely!
Can I control the music (Pause, Play, Skip, Stop)?
Only the Host or someone with the Admin Password can control the music. The Pause, Play, Skip, and Stop buttons are locked (🔒) by default so guests don't accidentally stop the party.

To unlock them, tap the ⚙️ (Admin) icon in the top right, log in with the Admin Password, and the buttons will be active for 10 minutes.
Can I move my reserved song to the top of the queue?
Yes! But you need the Admin Password to do this. Once you unlock the controls using the Admin Password, go to the 📋 Queue tab. You will see up (⬆️) and down (⬇️) arrows next to the songs. Tap the up arrow to move your song to the top or any other slot you want.

💡 Note: Guests cannot reorder the queue without the password to keep the party fair and organized.
Can I delete a reserved song?
Yes, you can delete a reserved song, but you need Admin Access (Admin Password). Once you unlock the controls, go to the 📋 Queue tab and tap the ✕ (remove) button next to the song you want to delete.

💡 Note: This is useful for removing duplicate requests or songs added by mistake.
Why do I get an "Admin only" error?
Only the host device should control playback. If you tap Skip or Stop without logging in as Admin, the app will block you. This keeps the karaoke party running smoothly without interruptions!
💝 Free & Privacy
Is VIDEoke YT really free?
Yes — 100% free, forever. No fees, no ads, no signup, no paywall. You can optionally tip the developer via the QR codes on the home page, but it's completely optional and the app will always work without it.
Are there ads?
No. Zero ad networks, zero sponsored content, zero popups, zero trackers.

⚠️ One honest caveat: the YouTube player itself may show ads if a specific video's uploader enabled ads on their video. This is YouTube's behavior, not the site. Pick videos from karaoke channels like Sing King, Stingray Karaoke, or most Filipino karaoke channels — those are ad-free.
Do you collect my data?
No. There's no analytics, no tracking pixels, no cookies. Only localStorage is used to remember your singer name and admin token on your own device.
🔧 Troubleshooting
A video won't play / "This video is unavailable"
YouTube blocks some videos from being embedded on other sites. The system auto-skips these and moves to the next song in the queue.

To fix: Pick a different video — search for "<song name> karaoke" on the Search tab.
Autoplay is blocked
Browsers require one user interaction before playing sound. When you open the host screen, a yellow overlay says "Tap Anywhere to Start" — tap it once, and from then on every song auto-plays.
Admin password doesn't work
Passwords are case-sensitive. Copy-paste directly from the home page or from the host screen — don't retype.
The party disappeared after a while
Parties auto-expire after 24 hours of inactivity — this is by design. On Render's free tier, sessions also reset when the backend sleeps/restarts.
